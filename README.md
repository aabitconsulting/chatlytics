# Chatlytics

Analytics and insights platform for conversational AI and chat interactions.

## Overview
Chatlytics provides telemetry, analytics, and performance evaluation for conversational interfaces.

## Getting Started

### Prerequisites
- Python 3.10+
- Git

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/aabitconsulting/chatlytics.git
   cd chatlytics
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # macOS/Linux:
   source .venv/bin/activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
